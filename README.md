# Dev Pratap Singh — 3D Portfolio

A recruiter-focused interactive portfolio for **Dev Pratap Singh**, Software Engineer.

## Highlights

- Interactive Three.js / React Three Fiber 3D hero
- Framer Motion scroll and entrance animations
- Responsive desktop, tablet and mobile layout
- Resume-driven profile, experience, education and technical skills
- Featured engineering projects with GitHub and live-demo links
- Backend, database, DSA and AI/GenAI skill groupings
- Accessible semantic sections and keyboard-friendly links
- SEO and social metadata
- Vercel-ready Vite configuration

## Tech Stack

React · Vite · Three.js · React Three Fiber · Drei · Framer Motion · Lucide React · CSS

## Run locally

```bash
npm install
npm run dev
```

For a production build:

```bash
npm run build
npm run preview
```
